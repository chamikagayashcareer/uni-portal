# Ashlar University Portal (Next.js + Tailwind, demo data)

    npm install
    npm run dev      # http://localhost:3000

Demo logins: admin@uni.edu / admin123, hod@uni.edu / hod123, lecturer@uni.edu / lec123, student@uni.edu / stu123

All data lives in `lib/data.js` and in React state (`lib/store.js`). Replace the `add / update / remove / login / register`
functions in `lib/store.js` with fetch calls to your Spring Boot REST API when it is ready.
